# 安装与首次使用

## 下载哪个
- M 芯片的 Mac（M1/M2/M3/M4…）：`TabPilot-<版本>-mac-apple-silicon.dmg`
- 英特尔芯片的 Mac：`TabPilot-<版本>-mac-intel.dmg`
- 不确定是哪种：点左上角苹果图标，选“关于本机”，看“芯片”那一行：写 Apple M… 就选 M 芯片版，写 Intel 就选英特尔芯片版。


## 安装
1. 双击 .dmg，把 TabPilot 拖进“应用程序”。
2. 第一次打开时，系统可能提示“无法验证开发者”。这是因为软件没有付费的苹果签名，不是病毒：
   - 在“应用程序”里**右键**点 TabPilot →“打开”→ 再点“打开”；
   - 如果还是打不开：打开“系统设置 → 隐私与安全性”，往下找到 TabPilot 那一行，点“仍要打开”。
3. 以后直接双击就能打开。

## 首次使用
1. 选一个模型服务商，填你自己的 API Key。软件会实际测试这个 Key，列出能用的模型，并推荐一个。Key 只用系统钥匙串加密保存在你自己的电脑上，不会上传到别的地方。
2. 右边是 Tableau Public。要保存作品需要登录 Tableau Public 账号（自己在右侧登录，软件不会代填密码）；只建图不保存的话不登录也能用。
3. 在左边输入需求，例如“新建 Web 制作工作簿并上传桌面上的‘销售数据.xlsx’”，然后“用我的数据，你能做哪些图？”。

## 常见问题
- **语音输入没反应**：第一次用麦克风时系统会弹窗询问，请允许“麦克风”和“语音识别”。之前点过拒绝的话，到“系统设置 → 隐私与安全性 → 麦克风 / 语音识别”里打开 TabPilot。
- **导出的文件在哪**：“下载”文件夹里的“TabPilot”文件夹。
- **发布/保存到 Tableau Public**：内容会公开，TabPilot 每次都会先问你，你同意才会点。
